Pizzería de fracciones

Prototipo de práctica interactiva. Hay cuatro niveles: construir, comparar, sumar y equivalentes.

Para subir de nivel necesitas 3 aciertos seguidos. Si fallas, el juego te explica el error y vuelves a empezar la racha.

Los ejercicios se generan al azar, así que casi nunca se repiten.

XP: 0

¡Dominaste las fracciones!

Esto es un prototipo: el mismo molde (ejercicios aleatorios, racha para subir de nivel y explicación del error) se puede repetir para cualquier tema.
